Ortak port sözleşmesi

✓

1 giriş + 2 çış + kontrollü geri dönüş

in: önceki akış • body: iterasyon gövdesi • exit: döngü sonrası • loop-back: yalnızca gövde sonundan loop node'a.

Node tipine özel ayar

While — condition

For — start, end, step, indexVariable

ForEach — items, itemVariable

Designer / Runner ortak davranışı

Canvas aynı port renderer ve validasyonunu kullanır.

Runner aynı loop-body yürütme altyapısını kullanır.

Normal node'ların keyfi cycle oluşturması yine engellenir.
